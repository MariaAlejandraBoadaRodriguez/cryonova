## Two-minute demo script

1. Open the site → **New investigation**.
2. Region by name: type `Colombia`, pick it (the map zooms to the box; it can be redrawn or edited by its corners).
3. Period: January 2005 → December 2024.
4. Variables: search `air temperature` (or `temperatura del aire`) → **Add**.
5. **Run live analysis**: progress shows CMR discovery, then monthly OPeNDAP reads (about 1 minute for 240 months); it can be cancelled.
6. Read the headline (+0.33 °C/decade with its 95% interval and p-value), the annotated chart, the seasonal trends and the provenance panel (product, version, granules, fetch time, grid window).

## Observed result (production, 2026-11-14 21:02 UTC)

240/240 months read live in 58.9 s; **+0.334 °C/decade (95% CI +0.044 to +0.624, p = 0.024, 20 complete years)**. See `docs/benchmarks/live-reads.md`.
